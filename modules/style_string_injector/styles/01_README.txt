Add both files to this folder, with matching names:

  My Photo Style.txt
  My Photo Style.png

Supported images: .png, .jpg, .jpeg, .webp (case insensitive).
The .txt must use UTF-8 text. File names become visible style names.
Styles only appear when BOTH files exist; the reserved style None is built-in.

Open Select Style and press Refresh Styles to discover new or edited files.
The dropdown also updates when the browser is opened.
Using ComfyUI's R / Edit > Refresh Node Definitions refreshes backend definitions;
existing nodes may additionally need Select Style > Refresh Styles.

There are no style-upload or style-editing features in the v0.1 gallery.
